# 0037 — Operator Overloading

Define how `+` (or an `add` method) combines two points, then add `(1, 2)` and `(3, 4)` and print `(4, 6)`. Like JavaScript, TypeScript has no operator overloading — a typed `add` method stands in. The constructor's `public x` parameter properties declare and assign the fields in one step.

## Run

    npx tsx main.ts
