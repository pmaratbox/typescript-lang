# 0029 — Bitwise Operations

Compute bitwise AND, OR, and XOR on `6` and `3`, plus a left shift of `6` by one bit, printing `and: 2`, `or: 7`, `xor: 5`, and `shift: 12`. The same 32-bit-integer bitwise operators as JavaScript, with `number` operands checked at compile time. The result is still a runtime `Number` produced by the 32-bit coercion.

## Run

    npx tsx main.ts
