# 0049 — Zip & Enumerate

Pair the letters `a, b, c` with the numbers `1, 2, 3` position by position, formatting each pair as `key=value` and printing `a=1 b=2 c=3`. The same index-based `map` as JavaScript; the element and index types are tracked statically. There is still no built-in `zip`.

## Run

    npx tsx main.ts
