# 0007 — Collections

Build an array of the integers `1, 2, 3, 4, 5`, then print its count and its
first and last elements. `number[]` (equivalently `Array<number>`) is a typed
array; the type is erased at compile time, so the emitted JavaScript matches
lesson 0007 in `javascript-lang`.

## Run

    npx tsx main.ts
