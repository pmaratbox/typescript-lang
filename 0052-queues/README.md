# 0052 — Queues

Enqueue `1`, `2`, and `3` into a queue, then dequeue them all and print them in first-in-first-out order: `1 2 3`. The same array-as-queue as JavaScript; `shift()` is typed `number | undefined`, so the `!` non-null assertion is used after the `length` guard.

## Run

    npx tsx main.ts
