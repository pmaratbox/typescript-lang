# 0012 — Enums

Define a `Color` enum (`Red`, `Green`, `Blue`) and print the integer value of
`Green` (1) and `Blue` (2). TypeScript has a real `enum` that auto-numbers its
members from 0. (Unlike most TypeScript types, an `enum` emits real JavaScript —
it is not erased at compile time.)

## Run

    npx tsx main.ts
