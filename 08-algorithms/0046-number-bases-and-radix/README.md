# 0046 — Number Bases & Radix

Print the integer `255` in hexadecimal, octal, and binary, producing `hex: ff`, `oct: 377`, and `bin: 11111111`. The same `toString(radix)` as JavaScript, returning a `string` for each base. Numeric literals support `0x`, `0o`, and `0b` prefixes for the reverse direction.

## Run

    npx tsx main.ts
