# 0032 — Math Functions

Take the square root of `16`, raise `2` to the 10th power, the absolute value of `-5`, and the larger of `3` and `9`, printing `sqrt: 4`, `pow: 1024`, `abs: 5`, and `max: 9`. The same `Math` methods as JavaScript, with the `number` results checked at compile time. There is one numeric type, so no integer/float distinction surfaces here.

## Run

    npx tsx main.ts
