# 0048 — Maps: Iterate & Transform

Build a map from letters to numbers (`a`->1, `b`->2, `c`->3), sum all its values, and print `sum: 6`. Typing the object as `Record<string, number>` keeps the values numeric through `Object.values` and `reduce`. The traversal is erased to the same runtime calls as JavaScript.

## Run

    npx tsx main.ts
