# 0026 — Sets

Build a set from `1, 2, 2, 3` so the duplicate collapses, then print its `size: 3` and whether it contains `2` (`has 2: yes`) and `5` (`has 5: no`). `Set<number>` is the typed view of the JavaScript `Set`; `.size` and `.has` behave identically and the element type is checked at compile time. The generic erases at runtime to a plain `Set`.

## Run

    npx tsx main.ts
