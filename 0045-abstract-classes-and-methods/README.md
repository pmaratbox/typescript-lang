# 0045 — Abstract Classes & Methods

Define an abstract `Shape` with an abstract `area` and a concrete `describe` that uses it, then implement a `Square` of side 3 and print `area: 9`. An `abstract class` with an `abstract` method cannot be instantiated and obliges subclasses to implement `area`, while the concrete `describe` is inherited. The checks are enforced at compile time.

## Run

    npx tsx main.ts
