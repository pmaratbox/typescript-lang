# 0036 — Inheritance & Overriding

Define a base `Animal` with a `speak` method, a `Dog` that overrides it, and call both, printing `animal: some sound` and `dog: Woof`. The same `class`/`extends` as JavaScript with type annotations. TypeScript also checks the override is compatible, and `override` can be required via the `noImplicitOverride` compiler flag.

## Run

    npx tsx main.ts
