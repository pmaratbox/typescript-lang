# 0667 — Big integer power

Raise an integer to a large power exactly using TypeScript's built-in `BigInt` type. The expression `2n ** 100n` uses the `**` operator on `BigInt` literals to compute 2 raised to the 100th power, yielding `1267650600228229401496703205376` with no floating-point rounding or overflow.
