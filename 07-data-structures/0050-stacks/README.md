# 0050 — Stacks

Push `1`, `2`, and `3` onto a stack, then pop them all off and print them in last-in-first-out order: `3 2 1`. The same array-as-stack as JavaScript; `pop()` is typed `number | undefined`, so the non-null assertion `!` is used after the emptiness check. No dedicated stack type exists.

## Run

    npx tsx main.ts
