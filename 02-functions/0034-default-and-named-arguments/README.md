# 0034 — Default & Named Arguments

Give a `greet` function a default greeting, then call it once without the greeting and once overriding it, printing `Hello, Ada` and `Hi, Ada`. The same default-parameter syntax as JavaScript with type annotations; like JS there are no named arguments, so an options-object parameter (`{ greeting }: { greeting?: string }`) is the typed stand-in.

## Run

    npx tsx main.ts
