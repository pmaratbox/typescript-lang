# 0006 — Functions

Define `add(a, b)` returning their sum, call it with `3` and `4`, and print
the result. Parameters are typed (`a: number, b: number`) and the return
type (`: number`) is annotated after the parameter list. TypeScript checks
these at compile time, then erases them — the emitted JS is the same as
lesson 0006 in `javascript-lang`.

## Run

    npx tsx main.ts
